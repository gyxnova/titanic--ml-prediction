# 🛳️ Titanic Survival Prediction (Kaggle)

## 📘 About
This beginner-friendly ML project predicts passenger survival on the Titanic using Python and data analysis techniques.

## 🧠 Concepts Used
- Data Cleaning
- Exploratory Data Analysis (EDA)
- Feature Engineering
- Logistic Regression
- Model Evaluation (Accuracy, Confusion Matrix)

## 📊 Accuracy
Achieved **~80% accuracy** on validation data.

## 🛠️ Tools
Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn

## 📁 Dataset
[Kaggle Titanic Dataset](https://www.kaggle.com/c/titanic)
